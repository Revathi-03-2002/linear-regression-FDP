# Linear Regression – FDP Hands-on

## 📌 Overview

This repository contains a hands-on Python notebook demonstrating **Simple Linear Regression** using student academic data.

The notebook helps beginners understand data analysis, visualization, and the process of building a machine learning model to predict exam marks based on study hours.

## 🎯 Objectives

- Explore and understand a dataset using Pandas.
- Perform basic statistical analysis.
- Visualize data using Matplotlib and Seaborn.
- Understand the relationship between study hours and exam marks.
- Build and train a Simple Linear Regression model.
- Make predictions and visualize the regression line.

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📂 Project Files

- `liner_regression_fdp.ipynb` – Jupyter Notebook containing the complete hands-on implementation.
- `Linear_Regression_FDP_Student_Dataset.xlsx` – Excel dataset used for analysis and model training.

## 📊 Notebook Contents

### 1. Data Loading and Exploration
- Import required libraries.
- Upload and load the Excel dataset.
- Display the first, last, and random rows.
- Explore dataset structure and statistical summary.

### 2. Exploratory Data Analysis (EDA)
- Calculate average, maximum, and minimum exam marks.
- Filter students based on marks and attendance.
- Sort students by exam marks.
- Analyze average marks based on attendance groups.

### 3. Data Visualization
- Scatter plot: Study Hours vs Exam Marks.
- Histogram: Distribution of Exam Marks.
- Correlation heatmap: Relationship between academic variables.

### 4. Simple Linear Regression
- Define independent variable (`Study_Hours`).
- Define dependent variable (`Exam_Marks`).
- Split the dataset into training and testing data.
- Create and train the Linear Regression model.
- Calculate the slope and intercept.
- Predict exam marks and visualize the regression line.

## 📐 Linear Regression Equation

The notebook demonstrates the Simple Linear Regression equation:

**y = mx + c**

Where:

- `y` – Predicted exam marks
- `x` – Study hours
- `m` – Slope of the regression line
- `c` – Intercept
